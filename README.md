# Jogo do Número Secreto em Java

Jogo de terminal para praticar os primeiros conceitos de POO.

## Conceitos praticados

- criação de classes e objetos;
- atributos privados;
- construtores e métodos;
- entrada de dados com `Scanner`;
- números aleatórios;
- estruturas condicionais e repetição.

## Como executar

```bash
javac -d out src/*.java
java -cp out Main
```

Escolha uma dificuldade e tente descobrir o número sorteado.
